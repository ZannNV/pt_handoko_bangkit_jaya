💡 Menjalankan Melalui VS Code Live Server

Anda dapat membuka file index.html ini melalui extension Live Server di VS Code (klik kanan index.html lalu pilih "Open with Live Server"). Live Server akan membuka portal ini di http://127.0.0.1:5500/index.html dengan kontrol viewer interaktif, switcher perangkat, dan status koneksi live.
